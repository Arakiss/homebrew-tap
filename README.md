# homebrew-tap

Homebrew tap for [eldr](https://github.com/Arakiss/eldr) — a zero-crate hardware monitor
and protective watchdog for Apple Silicon.

```sh
brew install Arakiss/tap/eldr
```

Builds from source (needs the Rust toolchain). Installs the `eldr` CLI; for the guard
daemon's `Eldr.app` bundle, use `make install` from the [eldr repo](https://github.com/Arakiss/eldr).
